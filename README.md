# StockWatch 대시보드

한국 상장 전종목 재무 스크리너(정적 페이지). `index.html` 하나로 동작하며 서버가 없다.

- 데이터: **DART 전자공시**(재무제표·배당·발행주식수) + **KRX/FinanceDataReader**(시세·상장정보)
- 갱신: 로컬 배치(`scripts/quarterly_update.py`)가 다시 만든 파일을 올린다.
- 관심기업·메모·테마는 **보는 사람 브라우저(localStorage)** 에만 저장된다 — 서버로 가지 않는다.
- 투자 판단의 근거로 쓰기 위한 것이 아니며 데이터 정확성을 보증하지 않는다.

마지막 빌드: 2026-10-25
